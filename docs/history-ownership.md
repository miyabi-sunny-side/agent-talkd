# 会話履歴と端末画面の取得責務

「会話」は過去のやり取り・報告を読み続ける機能、「画面」は Herdr の pane が
動作している様子を出先から確認する機能である。取得元と更新を独立させ、
会話履歴タブと端末画面タブの両方を維持する。

## 現在の取得元

| 機能 | 原本・取得元 | agent-talk の責務 |
| --- | --- | --- |
| 会話履歴 | Codex / Claude Code が保存する native JSONL。Herdr は対象の native session ID / path を提供する | `src/history.rs` が HOME 配下の対象履歴を解決・照合し、user / assistant 本文とページを返す |
| 端末画面 | Herdr CLI の `pane read <pane> --source visible --format text` | `src/herdr.rs` が対象の端末を取得前後に照合し、現在の表示テキストと取得成功時刻を返す |

会話の原本は各 CLI が所有する。agent-talk は別の会話 DB、複製ログ、独自の
セッション管理を持たない。HOME と native reader は現在の会話取得に使用する。
履歴の所在・環境条件は [README の環境変数](../README.md#環境変数)、取得上限と
カーソルは [HTTP API](../README.md#http-api) に従う。

端末画面は行と空白を保ったテキストであり、ピクセル画像や操作可能な端末ではない。
過去の報告・role・会話ページを含む native 履歴の代用にはしない。
会話を取得できない場合は会話側に理由を示し、端末画面は独立して閲覧できる。

## 更新とタブ切替

- 「会話」は直近ページから開き、新着は差分取得する。「古い会話」「新しい会話」で
  過去の本文を辿り、更新やタブ切替で読んでいるページ・位置を保持する。
- 「画面」は表示中かつ document visible の間、取得完了の2秒後に次の取得を行う。
  手動更新もできる。非表示では停止し、再表示時は即時に取得する。
- 両タブは同じ宛先・手紙の下書きを共有する。画面取得に会話の読取成功や送信可能な
  状態は要求しない。未登録・未対応 CLI・承認待ちでも、端末を特定できれば読める。
- 別の宛先を選ぶと以前の取得処理を破棄し、遅れて届いた内容を混ぜない。同じ pane の
  terminal、または取得時に固定した native session が変わった場合は更新を止め、
  対象の開き直しを案内する。
- 画面の取得失敗・切断・退出・入替後は、取得済みのテキストと成功時刻を残し、
  「以前の表示」であることと理由を示す。再取得が成功するまで現在の状態と扱わない。

UI の操作とポーリング条件の正本は [DESIGN.md](../DESIGN.md#9-polling-contract)。
取得処理は [内部設計](design.md) に従う。

## 以前の移譲案の扱い

2026-09-07 の要件整理により、会話履歴と端末画面を独立して維持することを
本タスクの成果とする。以前の文書にあった Herdr への native 履歴取得の移譲、
新規会話 API の追加、agent-talk の HOME / reader 削除は必須の次工程としない。
Herdr 本体の開発や配布を、この二つの機能を利用するための前提にはしない。
